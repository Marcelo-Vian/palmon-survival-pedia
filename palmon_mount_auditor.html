2. Preencha suas montarias

No print normal da montaria, preencha apenas Tenho, Lv e se ela está travada para não resetar. A Skill Lv é derivada do nível: 1-29 = Skill 1, 30-49 = Skill 2, 50-69 = Skill 3, 70-99 = Skill 4, 100+ = Skill 5.
